Guild Error Code

A co-op raid where your whole Knight Order takes on an Error Code boss

Translated from the Korean Developer's Note #61 (2.5-year roadmap). This is an early teaser under the working title 'Guild Error Code'; the name, mechanics and timing may change before it reaches global. Official Naver Lounge Developer's Note #61 (2026-06-16)

Overview

Guild Error Code is a planned co-op raid: your whole Knight Order tackles a powerful Error Code boss together, and placement is decided by the score your Order accumulates. It is the guild-scale counterpart to the solo Error Code: Diene world boss.

The developers frame it around cooperation: sharing strategies with your guildmates and building your Order's own approach to the boss together, for the fun of banding up against an overwhelming enemy.

How it relates to other modes

  • •Solo version: the seasonal Error Code: Diene world boss, where each Guardian builds their own score.
  • •This mode: the same 'Error Code' boss concept, but scored and ranked per Knight Order rather than per player.

※ This is a roadmap teaser under a working title, so specifics (boss, scoring, rewards) are not final and may differ at global.
